BALDI'S BASICS3D · Classic Remastered clone

Collect all 7 notebooks, solve the math, and escape the schoolhouse.
Every wrong answer makes Baldi angrier. Don't run in the halls near the Principal!

Build · Fan-made tribute. Not affiliated with Basically Games. All art, sound and code is original and procedurally generated.

How to play

  • Move: WASD / arrows · left stick · Look: mouse · right-side drag
  • Run: Shift · RUN button (uses stamina)
  • Use / open / take: E, Space or click · USE button
  • Use item: right-click or F · ITEM button · pick slot: 1-3 / wheel / tap
  • Map: M · Pause: Esc / P
  • Zesty Bar – refills stamina
  • BSODA – spray ahead; shoves and stuns Baldi
  • Alarm Clock – set it down; Baldi runs to the ring
  • Quarter – buy from the BSODA vending machines
  • Principal's Keys – unlock the Principal's office
  • Safety Scissors – escape detention

Beware: Playtime makes you jump rope while Baldi closes in, It's a Bully steals items, Gotta Sweep sweeps everyone down the hall, and the Principal punishes running.
